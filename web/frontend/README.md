## <center> Telepítés és indítás

## 1. Frontend telepítése és indítása
    A "frontend" mappán belül az alábbi parancsot futassa:
    npm install
    npm run dev

## 2. Backend telepítése és indítása
    A "backend" mappán belül az alábbi parancsot futassa:
    npm install
    node app.js
